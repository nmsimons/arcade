Your Arcade data

You can play without signing in. Anonymous saves and personal bests stay in your browser. Local level folders stay on your device.

Optional accounts and cloud storage

Signing in with Google or a personal Microsoft account creates a separate save space on this device. Arcade uses your provider account identifier to separate saves and displays your account name while you are signed in. Signing in does not automatically copy anonymous progress.

Enabling cloud storage is a separate choice. Google Drive access is limited to hidden storage for this app. OneDrive access is limited to the application's folder, normally under Apps. Cloud files contain game saves, custom levels, personal bests and version metadata. They are not public leaderboards.

Your browser sends this data directly to your storage provider. Arcade has no account database, save upload service or server token store. Access tokens are held in browser memory. Google and Microsoft process sign-in and storage requests under their own privacy policies. The site host may retain ordinary request logs such as IP addresses and requested paths; this page does not promise that hosting providers keep no logs.

Control and recovery

  • Cloud sync runs at the arcade menu. During play, progress is saved locally. Wait for sync to finish before closing the browser.
  • Each cloud sync that changes data creates a version. Conflicting versions are retained until you choose which progress to continue.
  • Sign-out clears the app's credentials and returns to anonymous play. It keeps your local and cloud saves. Browser caches are not encrypted private vaults; someone using the same browser profile may access them.
  • Disconnecting stops cloud sync. To revoke the app's grant, use your provider's permissions settings. This is separate from signing out.
  • Use Export all game data to keep a portable JSON backup. You can restore that backup through Import backup.
  • Clear the site's browser data to remove local copies. To remove cloud copies, delete the Arcade app folder in OneDrive, or remove Arcade's hidden app data in Google Drive's Manage apps settings. Disconnect first so future syncs do not recreate data.

Files count toward your storage quota. Arcade retains cloud versions and does not automatically delete older saves. Revoking permission alone does not necessarily delete data.
